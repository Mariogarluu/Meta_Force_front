Pipes, Directivas y ControlValueAccessor implementados

📊 Pipes Personalizados

1. TimeSince Pipe

Convierte fechas en texto de tiempo transcurrido legible.

@for (item of sampleDates; track item.label) {
{{ item.label }}
{{ item.date | timeSince }}
Fecha: {{ item.date | date:'short' }}
}

2. RoleName Pipe

Formatea códigos de roles en nombres legibles.

@for (role of sampleRoles; track role) {
{{ role }}
{{ role | roleName }}
}

3. StatusBadge Pipe

Retorna clases CSS para badges de estado con colores apropiados.

@for (status of sampleStatuses; track status.key) { {{ status.label }} }

✨ Directivas Personalizadas

1. Highlight Directive

2. Permission Directive

Muestra u oculta contenido según el rol del usuario autenticado:

👑
Solo SUPERADMIN
Este contenido solo es visible para Super Administradores
👨‍💼
Administradores
Visible para SUPERADMIN y ADMIN_CENTER
💪
Staff
Visible para administradores y entrenadores

3. ClickOutside Directive

Detecta clics fuera del elemento. Útil para cerrar dropdowns:

@if (dropdownOpen) {
Menú Dropdown
Haz clic fuera de esta caja para cerrarla automáticamente
}
